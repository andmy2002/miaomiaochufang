# 喵喵厨房

Cocos Creator **3.8.8** 工程，目标平台为微信小游戏和抖音小游戏。项目从旧版 Creator 工程迁移而来；打开本目录时选择 Creator 3.8.8，启动场景为 `assets/scene/loadScene.scene`。

## 当前状态

浏览器预览可完成大厅、面板、一局订单、结算及重开。微信与抖音小游戏的本地构建已通过，但仓库不包含生成的 `build/` 产物，也未配置正式 AppID、广告位 ID 或抖音分享模板 ID。构建步骤见 [`build-configs/README.md`](build-configs/README.md)，迁移和验收详情见 [`阶段E_微信抖音适配与构建验收.md`](阶段E_微信抖音适配与构建验收.md)。
