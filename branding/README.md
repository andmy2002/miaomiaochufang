# 喵喵厨房品牌素材

这四张图片是为本项目新绘制的品牌素材。整体采用当前游戏素材的二维卡通风格：深棕色粗描边、薄荷绿色底色、橙黄色食物和紫色厨师帽。请在微信、抖音小游戏后台上传前，按各平台当时的尺寸和裁切要求另存适配版本；这里保留原始图。

绘制提示词要点：

1. Logo：透明背景的「喵喵厨房」中文标题，橙黄色圆润手绘字体、深棕描边、紫色厨师帽和汉堡点缀，匹配现有卡通食物素材。
2. 图标：正方形薄荷绿背景，戴紫色厨师帽的白色小猫端着汉堡，深棕描边、明亮柔和配色，缩小时仍清晰。
3. 启动图：竖版小猫厨房场景，保留顶部「喵喵厨房」标题和中心角色，薄荷绿主色与橙黄色食物呼应，留出安全边距。
4. 分享图：横版 16:9 场景，左侧「喵喵厨房」标题、右侧小猫厨师与汉堡，沿用相同描边、帽子和主色。

抖音加载图的 640 × 1385、PNG/JPG、2 MB 上限以抖音官方当前文档为准；此图已做居中裁切，不含进度条和虚构数值。微信分享图按官方示例采用 5:4 比例。微信、抖音的图标上传入口与大小限制仍须以实际开发者后台显示为准；本项目目前没有 AppID，也未执行平台构建，不能将准备好的素材等同于后台审核通过。

微信 5:4 分享图使用内置图像编辑工具从已确认的横版分享图扩展画布：保留原「喵喵厨房」标题、小猫、汉堡和配色，在上下方向延展同一厨房背景，不添加新文字或水印；随后按目标尺寸缩放。其他平台导出图为原图的确定性缩放或居中裁切。

两个平台图标使用内置图像编辑工具从已确认原图制作方形上传版：仅去除原图的圆角/透明角，以薄荷绿补全四边，并给帽子、耳朵、爪子与汉堡留出完整安全边距；原始图标不变。
